# 🤖 IA Actu FR

Agrégateur d'actualités sur l'intelligence artificielle en français.

## 🚀 Installation

### 1. Cloner le projet
```bash
git clone https://github.com/vialj99/ia-actu-fr.git
cd ia-actu-fr
```

### 2. Configurer l'API

1. Copiez le fichier de configuration exemple :
```bash
cp config.example.js config.js
```

2. Obtenez votre clé API gratuite sur [NewsAPI.org](https://newsapi.org/register)

3. Ouvrez `config.js` et remplacez `VOTRE_CLE_API_ICI` par votre clé :
```javascript
const CONFIG = {
    API_KEY: 'votre_vraie_cle_ici'
};
```

### 3. Ouvrir l'application

Ouvrez simplement `index.html` dans votre navigateur !
